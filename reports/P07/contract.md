# Контракт ggd-v4

Расширение ggd-v3: честные тайминги включены, oracle выключен. Старые поля,
их порядок и приватность не меняются. После полного packed ggd-v3 добавлены
две строки героев по 32 float: 16 значений, затем 16 флагов известности.
В декодированном входе расширяется только `hero_combat`: 44 → 76 столбцов;
полный вход hero encoder: 140 → 172. Остальные энкодеры сохраняют размер v3.

| Столбцы значений | Смысл | Делитель |
|---|---|---:|
| 0…4 | one-hot: нет каста, ближний/средний/дальний койл, ульта | 1 |
| 5 | прошедшая доля cast point от **наблюдаемого** начала | 1 |
| 6…9 | секунды с наблюдаемого начала каждого скилла, насыщение 60 с | 60 |
| 10…13 | уровни четырёх скиллов | 4 |
| 14 | стаки дебаффа койла | 16 |
| 15 | оставшееся время дебаффа, с | 10 |

Порядок скиллов совпадает с `SPELLS`. Фаза считается по наблюдаемому переходу
`IsCastingAbility`/`GetCurrentActiveAbility`, с cast point 0.55/1.67 с.
`GetAnimActivity/GetAnimCycle` не различают три койла: в зонде activity=1500,
cycle продолжает idle-анимацию. Ульта activity=1515. Фаза v4 — причинная оценка,
не приватный CAST_END: если первое наблюдение попало в середину каста, фаза
неизвестна. Пропуск >0.2 с или потеря видимости сбрасывает отслеживание фазы.

Вражеский `GetCooldownTimeRemaining` возвращает -1, несмотря на ненулевые
кулдауны у собственного наблюдателя. Его значение не используется. Уровни
доступны. Исторические часы отмечают **начало**, включая отменённый каст;
это не обещание, что эффект произошёл, и не готовый прогноз кулдауна.
Часы известны только после наблюдаемого перехода. История сохраняется в тумане,
но вся строка невидимого героя обнуляется, включая known. При возвращении
видимости доступны часы ранее наблюдавшихся событий, без событий из тумана.

Lua `agent.public_spells` применяется в HTTP snapshot и native supplement
`UnitExtra.v4_json`; native v4 отклоняет запись без этого supplement.
В настройках запуска Dota требуется `observation_profile="ggd-v4"` и заново
собранный native collector. Старые записи не содержат нужных полей.

Сбор: `observation_profile: "ggd-v4"`, `teacher_version: "v10"` в collect JSON.
Формат контейнера GGDDemo2 остаётся 3, версия наблюдения в header/signals — 4.
`ggd_dataset.py` читает новый формат; PyTorch/Burn модели и экспорт распознают
размер 172. Обучение в P07 не запускалось; тренировочный CLI train_ggd пока
сохраняет прежние разрешённые профили v2/v3. Сбор DAgger v4 не включён.

Паритет: реальные Lua-значения сравниваются с Python и с производственным GPU
observer на той же последовательности публичных событий. Это проверяет
кодировку, шкалы, известность, скрытие и память; не доказывает совпадение
полных игровых траекторий. Метрики: `lua-python-parity.json`, `gpu-parity.json`.

Дополнительно `actual-cast-parity.json` сравнивает четыре реально исполненных
каста GPU-физики с Dota. Начало наблюдаемого каста и первый эффект выравниваются;
на границе окончания допускается один тик (33.3 мс). Трассы симулятора сохранены
в `simulator-cast-traces.csv`; данные Bot API — в `api-events.csv`.
