## RL-настройки P08

| Параметр | Основной прогон |
| --- | --- |
| Среда / соперник | Окружение 003, профиль `ggd-v2`, teacher-v9 |
| Параллельные матчи | 192 арены; независимые перезапуски, стороны чередуются |
| Rollout / minibatch | 128 решений; 48 последовательностей ×128, 2 PPO-эпохи |
| Оптимизатор / lr | Веса из checkpoint 54 выбранной пробы; новый Adam, lr=1e-5, epsilon=1e-8 |
| Critic lr | 3e-4 при отдельном critic-only прогреве; после него совместный PPO использует lr=1e-5 |
| Якорь | Исходная M2; коэффициент KL(current‖M2) 0.2→0.05 |
| PPO / GAE | Clip 0.2, grad norm 0.5, gamma 0.99, lambda 0.95 |
| Value / entropy / stop | Value coefficient 0.5, normalized entropy 0.005; stop-KL 0.02 к rollout-политике |
| Память / команды | Сброс LSTM каждые 128 решений и после смерти; решения каждые 4 тика, offset=6 |
| Длительность / оценки | 120 минут PPO, 323 блока; sampling и argmax по 64 матча через 60 минут |

Общий critic-only прогрев: минимум 30 блоков после 0:00, среднее EVpost0
последних пяти post-блоков >0.3 и ненулевая reward текущего блока; предел —
150 блоков. Завершился по лимиту с last5 EV=0.148, продолжение разрешено
пользователем. Во время прогрева сохранены 55/55 тензоров вне value head;
изменились 4/4 value-тензора. Pregame участвует во всех losses.

Рассинхронизация перед каждой пробой и main: 40 блоков случайно переставленных
задержек активации арен под замороженной политикой, без rollout и обновлений
оптимизатора. Затем терминальные арены независимо сбрасываются на границе
128 решений. Начальный frozen-префикс учитывается отдельно от обучения.

Награда, девять компонентов: свой LH +1, deny +0.5; LH соперника −0.5,
deny соперника −0.25; своя/чужая смерть −10/+10; потеря/уничтожение центральной
T1 −10/+10; результат по LH на 600 с ±5, ничья 0.

Команда `train-ggd` поддерживает профили v2/v3; PPO с ggd-v4 в P08 не интегрирован.
[Конфиг main](P08/revised/main.json), [прогрев](P08/revised/critic.json),
[рассинхронизация](P08/revised/desync-validation.json), [описание P08](P08.md).

## Профиль наблюдений ggd-v4

Профиль [P07](P07.md) расширяет честный ggd-v3: `timing_honest=true`,
oracle выключен. После прежнего packed-входа добавлены две строки героев
по 32 float: 16 значений и 16 флагов известности. `hero_combat` расширен
с 44 до 76 столбцов, полный вход hero encoder — со 140 до 172.

Добавлены тип текущего каста (one-hot «нет/три койла/ульта»), причинная фаза
cast point, часы с наблюдаемого начала каждого из четырёх скиллов, их уровни,
стаки и оставшееся время дебаффа койла. Часы включают отменённые касты;
кулдаун врага из скрытых данных не подставляется. Невидимая строка героя
обнуляется вместе с known; фаза неизвестна, если начало каста не наблюдалось.

Native-вход требует `observation_profile="ggd-v4"`, заново собранный collector
и supplement `UnitExtra.v4_json`. Старые записи не содержат этих полей.
В P07 модели не обучались; обучение и DAgger v4 не включены.
Полная схема, шкалы и ограничения: [контракт ggd-v4](P07/contract.md).
