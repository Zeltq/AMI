При `sv_cheats 1`: 1/1 загрузок; `GameRules:GetGameModeEntity()` непригоден для таймера обычной игры,
поэтому таймер установлен на существующего SF, как в P15.
В Bot API обеих сторон 0/2 VM имеют ExecuteOrderFromTable, SendToServerConsole,
SendToConsole, Convars, GameRules или Entities. Автозапуск серверного кода этими средствами невозможен.
Бот передаёт собственный player ID и точку, policy server записывает локальный Lua-файл приказов;
серверный мост читает только команды и пишет ACK, привилегированные наблюдения модели не передаёт.
Шаги человека после подготовки файлов: Local Host + Local Dev Script, выбрать SF и дождаться героев;
открыть консоль, выполнить `sv_cheats 1`, затем `script_reload_code bots/p17_bridge`.
Это 2/2 консольных команды; запуск policy server и установка будут описаны в пункте5.

идентичность listen-server. Графический клиент запрещён заданием и не запускался.
Артефакты: `bridge-001` (ошибка GetEntityIndex), `bridge-002` (таймер), `bridge-003` (успех).
Повторные запуски используют один разрешённый пользователем executable:
`C:/AMI/runs/p17/bridge-001/runtime/game/bin/win64/dota2.exe`; bind 127.0.0.1.
