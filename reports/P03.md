## Ограничения и что не проверено

- GPU-конфиг задаёт pregame=83 с; первые кадры Dota около −90 с. Сдвиг игрового времени выхода на мид около 7 с объясняется началом отсчёта; длительность от первого кадра близка. [environment-summary.json](P03/environment-summary.json).
- Dota принимает seed команды выбора героя; глобальный RandomSeed API отсутствует. Полная повторяемость игрового RNG Dota не установлена. Для GPU принятая матрица имеет 200/200 разных стартов; прежняя группа исключена по арифметическому критерию до готовности новой. [rng-audit.json](P03/rng-audit.json).
- Ошибок выполнения Lua 0/20. Часы GetLastAttackTime согласованы с первыми наблюдениями 27/27 собственных снарядов в 90-секундной диагностике, задержка ≤1 тика. Оценка windup в Lua остаётся приближённой; конкретный баг порта не доказан. [attack-clock.json](P03/attack-clock.json).
- Атаки Dota считаются по GetLastAttackTime, GPU — по завершённым циклам ATTACK_READY. Тип целей GPU выведен из нулевых hero/structure/HOLD-команд и отсутствия свободного поиска цели у героя без HOLD; raw-команды не подменяют этот счётчик.
- GPU-ресурсы в снимках округлены до FP16, позиции LH наблюдаются на первом решении после LH (шаг 4/30 с). Для 600 с используется полная терминальная телеметрия GPU. Конкретные механические причины п.3 остаются гипотезами.
