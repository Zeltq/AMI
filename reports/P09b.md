- Checkpoint и кэш критика сохраняются атомарно; тест прерванной записи сохраняет прошлый checkpoint. Кэш фиксированного hidden — FP16; config фиксирует SHA датасетов. GPU smoke критика пройден; полное предобучение и экспорт сохранили политику.
- Для ревью сохранены статистики каждого матча в `P09b/*-vs-*-SEED.json` без покадровых реплеев, вместе с аргументами оценок и SHA манифестов весов.

- Исправление minibatch: potential-v1 выбирает 48 последовательностей ученика, исключая строки соперника; прежний режим P08 сохраняет свой порядок. Целевой CPU Rust-тест 1/1.
- `ggd_ppo.rs`: ggd-v4/v10, отдельный lr value-головы, восстановление model/Adam/времени KL, оценки обоих соперников внутри процесса. `imitation.rs`: --opponent-weights для разных моделей; `teacher_eval.rs`: reward обеих сторон.

Один проход новых train-последовательностей, не менее половины новых кадров в батче; AdamW из предыдущего checkpoint, lr 1e-4, batch 8×128, clip 1, wd 1e-5. ATTACK крипов/башен 4, героя 1; near/mid/far 4/2.93/4, как в P09a.
- Итоговые параметры RL: 192 арены, batch 48×128, epochs 2, actor lr 3e-5, critic lr 3e-4, clip 0.2, entropy 0.005, stop_kl 0.02, gamma 0.99, GAE lambda 0.95. KL 0.05→0.01 за 480 минут без сброса; оценки отдельно от времени обучения.
- Решение: оценки sampling на seed 20261103/20261104, по 64 матча; 64 за сторону суммарно. P09a переиспользуется только при полноте полей; недостающая награда требует повторной оценки с новым логированием.
- Решение: полезный койл проверяется по изолированному вкладу события; общий шаг дополнительно содержит (gamma−1)×старый потенциал. Проверка телескопирования использует дисконтированную сумму и конечный потенциал 0.
