# Человек против ZOg 000470

Обычная Dota из Steam, штатные боты **Local Dev Script**, локальное лобби.
Модель работает на CPU в отдельном PowerShell. Dota запускает пользователь.

**По уточнению пользователя дуэль заканчивается при первой смерти любого участника.**
После этого выходите из игры; продолжение после респавна не поддерживается.
Второй предел — 10:00. Отметки 5:00/10:00 в отчёте будут `null`, если дуэль закончилась раньше.

## 1. Подготовка

Закройте Dota. Откройте PowerShell:

```powershell
Set-Location C:\AMI-wt\P10
python scripts/install_play_bot.py --human-team 2
```

`2` означает: вы Radiant, ZOg Dire. Для обратной стороны сначала восстановите
папку командой из раздела 6, затем установите с `--human-team 3`.

Установщик копирует всё прежнее содержимое в `C:\AMI\runs\p10\bots-backup-<время>`,
проверяет SHA-256 каждого файла и только затем устанавливает скрипты. Сам каталог
или junction `game\dota\scripts\vscripts\bots` сохраняется. Путь резервной копии
и состояние установки записаны в `C:\AMI\runs\p10\installation.json`.

Локальные зависимости: Windows Python с PyTorch/NumPy/protobuf, уже экспортированный
`C:\AMI\runs\p10\ZOg-000470.pt` и `C:\AMI\runs\p10\nativecollect.exe`.
Если эти артефакты отсутствуют, из корня worktree:

```powershell
python gpu/scripts/export_policy.py C:/AMI/runs/p09/P09c/continue90/rl-continue-001/checkpoint-000470/weights C:/AMI/runs/p10/ZOg-000470.pt
Push-Location tools/nativecollect
go build -o C:/AMI/runs/p10/nativecollect.exe .
Pop-Location
```

## 2. Параметры Steam

Steam → Библиотека → Dota 2 → Свойства → Общие → Параметры запуска.
Сохраните свою прежнюю строку отдельно и добавьте к ней:

```text
-console -condebug -insecure -botworldstatetosocket_radiant 12250 -botworldstatetosocket_dire 12251 -botworldstatetosocket_frames 1 -botworldstatesocket_threaded
```

`-condebug` нужен для передачи публичного supplement и подтверждений команд через
`game\dota\console.log`; два локальных TCP-порта передают worldstate.
Policy server использует `127.0.0.1:12360`. RCON и пароль RCON не нужны:
единственную команду подготовки вводите в игровой консоли.
Разрешение, графику и остальные обычные настройки менять не требуется.

## 3. Запуск policy server и лобби

В PowerShell, до запуска Dota:

```powershell
Set-Location C:\AMI-wt\P10
python scripts/play_vs_model.py
```

Дождитесь `CPU policy ready`. Затем самостоятельно запустите Dota из Steam.
Создайте приватное лобби:

1. Режим **1v1 Solo Mid / 1 на 1 на средней линии**.
2. Сервер **Local Host / Локальный сервер**.
3. Боты обеих сторон: **Local Dev Script / Локальный скрипт разработки**.
4. Включите заполнение пустых слотов ботами и читы для локальной подготовки.
5. Займите Radiant при `--human-team 2`, Dire при `--human-team 3`.
6. Начните матч и выберите **Shadow Fiend / Nevermore**.

После появления героя можно нажать **F9**. Откройте консоль клавишей,
назначенной у вас для консоли; при необходимости назначьте её в настройках Dota.
Введите по очереди:

```text
sv_cheats 1
script_reload_code bots/play_model_setup
```

Подготовка проверяет одного человека SF на выбранной стороне, оставляет одного
вражеского SF и удаляет лишних ботов. В консоли должен появиться
`SF_PLAY_DUEL_READY|2` (или `|3`), в PowerShell — `Duel connected`.
После этого снимите паузу F9. Не вводите команду повторно в том же матче.
Команда `script ...` в проверенном выделенном сервере недоступна; нужна именно `script_reload_code`.
Если нет `Duel connected`, оставьте игру на паузе: проверьте сторону человека,
выбор SF, Local Dev Script и строку параметров запуска. Сохраните путь сессии
и сообщение ошибки из PowerShell для разбора; повторный запуск — в новом матче.

## 4. Правила сравнения и завершение

**Модель учили только до первой смерти и до 10:00; для честного сравнения — SF
на миде без рун, Bottle, Soul Ring и нейтральных предметов.**

F9 ставит и снимает паузу. Первая смерть любого SF завершает дуэль.
После first blood выходите из матча. При достижении 10:00 скрипт также завершает
оценку. Для досрочного прекращения нажмите Ctrl+C в PowerShell и выйдите из матча.
Python останавливает свой policy server и collector; клиент Dota остаётся под вашим управлением.

В конце PowerShell печатает итог; JSON сохраняется в `summary.json`: first blood с погибшей стороной, убийцей и
игровой секундой; LH/deny обоих на 5:00/10:00, смерти, касты и попадания койлов.
Попадания — события урона по целям; одно применение может задеть несколько целей.
Попадания по герою приведены отдельно. `null` означает отсутствие измерения.

## 5. Телеметрия

Каждая сессия: `C:\AMI\runs\p10\human\<время>\`.
`native-decisions.pb.gz` содержит наблюдения, решения, команды и ACK;
`dota.log` — HP/LH/deny по времени и серверные события; `summary.json` — итог;
`service\stats.json` — состояние инференса. Для повторного расчёта:

```powershell
python scripts/play_vs_model.py --summarize C:/AMI/runs/p10/human/<время>
```

Сообщите в чате, что сыграли; путь сессии поможет выбрать нужный матч.

## 6. Восстановление

Закройте Dota. В PowerShell:

```powershell
Set-Location C:\AMI-wt\P10
python scripts/install_play_bot.py --restore
```

Восстановление сохраняет ещё одну полную копию текущего содержимого, возвращает
исходные файлы и пустые каталоги, удаляет добавленные файлы и проверяет SHA-256.
В Steam верните сохранённую прежнюю строку параметров запуска, удалив добавленные
выше параметры. Установщик не меняет параметры Steam автоматически.

## Граница проверки

Сокеты, native ggd-v4 и `script_reload_code` проверяются на выделенных серверах.
Полный путь с человеком в обычном графическом клиенте будет проверен вашим матчем;
агент графическую Dota не запускал. Измерения переноса и ограничения — `reports/P10.md`.
